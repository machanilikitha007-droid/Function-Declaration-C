# Function Declaration in C

A simple C program that demonstrates how to declare a function before
main() and define it later in the program.

## File

function_declaration.c

## Concepts Used

- Function declaration
- Function definition
- Function call
- Return value

## How to Run

gcc function_declaration.c -o function_declaration
./function_declaration
